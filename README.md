# Emergency Alert System – Admin Dashboard

## Overview
This repository contains the web-based administration dashboard for the Emergency Alert System.

It enables authorized users to create, manage, and monitor alerts in real time, as well as oversee system performance and user activity.

---

## Technology Stack
- Laravel (Blade) OR React (optional)
- REST API integration with backend
- Bootstrap / Tailwind CSS

---

## Core Features
- Secure login and authentication
- Role-based access control
- Alert creation and geo-targeting
- Real-time alert monitoring
- Reporting and analytics dashboard
- Audit logs and system tracking

---

## Project Structure
- /resources/views     → UI templates (Blade)
- /components          → UI components (if using React)
- /services            → API integration services
